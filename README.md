# WorkoutDiary

Тема проєкту: «Щоденник тренувань».

WorkoutDiary — вебзастосунок для обліку тренувань. Він дає змогу
зберігати назву заняття, дату, тривалість, дистанцію, показники пульсу,
статус виконання та власні нотатки.

Основний тип даних — Workout. Запис тренування містить ідентифікатор,
назву, дату проведення, тривалість у хвилинах, дистанцію в кілометрах,
мінімальний і максимальний пульс, статус та необов'язкову нотатку.

Особливість проєкту — порівняння двох періодів. Користувач зможе обрати
два проміжки часу та побачити поруч кількість тренувань, сумарну
тривалість, загальну дистанцію і динаміку показників.
